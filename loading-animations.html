Loading States — Narrava

Three variants built on the logo mark. Swap the placeholder mark for your real logo image and drop the CSS + markup into any loading spot on the site.

Variant 1 — Spin Ring

N

Logo stays fixed in the center; a ring spins continuously around it. Best for compact inline loaders (buttons, cards, table rows).

Variant 2 — Pulse Breathe

N

The logo gently scales up and down while soft rings pulse outward from behind it. Best for full-page or full-panel loading states.

Variant 3 — Orbit Dots

N

Three dots orbit the still logo like satellites. Best for upload/processing states — e.g. while Bunny Stream is transcoding an episode.
